# Theme

The interface offers three color themes, and two places to choose between
them. The **theme button** in the header — next to the Wi-Fi and Bluetooth
signal icons — cycles through the modes one tap at a time: automatic, light,
dark, and back to automatic. The icon itself shows the active mode: an empty
circle for light, a half filled circle for automatic, and a full circle for
dark.

The **Admin → Frontend** group also holds a **Theme** select for the same
choice. Both controls stay in sync, so you can jump with the header button
and confirm or change the saved mode later in Admin.

- **Auto** (default) follows the light or dark preference of the phone or
  computer you are browsing from, and switches on its own when the system
  changes.
- **Light** and **Dark** fix the interface to that palette whatever the
  system does.

The choice is saved per browser on the device you browse from, so a phone
and a laptop can use different themes with the same controller. It lives in
the browser's local storage rather than the controller's saved
configuration: clearing the site's browser data returns the interface to
Auto, and a [factory reset](factory-reset.md) does not change it.
